# Revenue: Revenue Analytics
Built by **@madhav1-007** as part of Crestline (Analytics & Data Visualization).

## Research
- **What it is:** A chart and headline number showing how much money came in over a time range.
- **Where it is used:** SaaS dashboards, shop admin panels, finance tools.
- **Why it matters:** Revenue is the first number most teams check, so it must be clear at a glance.
- **Patterns observed:** Big number with change, range switcher, bar chart, hover readout.
- **What this version adds:** Bars that grow in a wave, an animated count-up, and plain-language change text.

## Files
`index.html`, `style.css`, `script.js`. Open `index.html` in a browser. Uses sample data only.

## Optional: Ask Gemini
The page has a box where a visitor can paste their **own** Gemini API key and ask a question about the chart. The key is kept only in the input box (never saved, never committed). Without a key the page works as normal. If the model names in `script.js` stop working, update the `MODELS` list.
