# Funnel: Conversion Funnel
Built by **@madhav1-007** as part of Crestline (Analytics & Data Visualization).

## Research
- **What it is:** A staged chart showing how many people reach each step toward a goal.
- **Where it is used:** Marketing and product analytics, checkout reviews.
- **Why it matters:** It shows the exact step where the most people give up.
- **Patterns observed:** Narrowing bars, percent of previous step, week comparison.
- **What this version adds:** Bars that fill one after another, and a drop-off count under each step.

`index.html`, `style.css`, `script.js`. Open `index.html` in a browser. Uses sample data only.
