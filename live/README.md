# Live: Real-time Analytics
Built by **@siddupati4-hue** as part of Crestline (Analytics & Data Visualization).

## Research
- **What it is:** A view that updates continuously to show what is happening on a site right now.
- **Where it is used:** Operations screens, launch-day monitoring, news and e-commerce sites.
- **Why it matters:** Some decisions cannot wait for a daily report.
- **Patterns observed:** Rolling line chart, current count, ranked list, pause control.
- **What this version adds:** A pulsing marker on the latest point and a pause and resume button.

## Files
`index.html`, `style.css`, `script.js`. Open `index.html` in a browser. Uses sample data only.
